SharePoint-friendly rollout

Use a hosted deployment for live updates, or provide an offline desktop bundle for staff who need downloadable access.

Recommended

Hosted online workspace

  • Deploy this Flask app to Azure App Service or a container host.
  • Add the app URL to SharePoint as a site link or embed web part.
  • Keep pricing, governance documents, and templates centralised.
Offline option

Downloadable desktop package

  • Bundle the app for Windows distribution when offline access is needed.
  • Store the installer in a SharePoint document library.
  • Publish release notes so staff know when governance data changes.

Implementation notes

Detailed deployment instructions live in DEPLOY_SHAREPOINT.md. If you later move this into the correct WindgapNDIS repository, this Flask UI is ready to transfer alongside the quote and document engines.
